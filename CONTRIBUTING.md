# Contributing to Awesome SEO Skills

The README is the source of truth for this list.

## Before adding a skill

- Link to the original public repository or the publisher's official skill page.
- Confirm that the skill has a specific SEO, GEO/AEO, or SEO-adjacent use case.
- Read the skill's instructions and any scripts or dependencies it includes.
- Do not add prompt collections, generic marketing advice, inactive projects, or unverified mirrors.

## Pull request checklist

1. Add the skill alphabetically in the relevant category.
2. Describe its practical SEO use case in one factual sentence.
3. Name meaningful dependencies or credentials in the notes column.
4. Keep descriptions concise and avoid unverified ranking or traffic claims.
5. Do not add affiliate links, sponsored placements, or tracking URLs.

## Quality bar

We prioritise public, inspectable skills with clear workflows and useful outputs. Inclusion does not imply endorsement, security review, or a ranking guarantee.
